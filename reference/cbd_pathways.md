# CBD introduction pathway categories

The six main pathway categories of the Convention on Biological
Diversity classification (CBD 2014; Hulme et al. 2008,
[doi:10.1111/j.1365-2664.2007.01442.x](https://doi.org/10.1111/j.1365-2664.2007.01442.x)
).

## Usage

``` r
cbd_pathways()
```

## Value

A character vector.

## Examples

``` r
cbd_pathways()
#> [1] "release"     "escape"      "contaminant" "stowaway"    "corridor"   
#> [6] "unaided"    
```
